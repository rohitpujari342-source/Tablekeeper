# STEP 3 — INSPECT FOR HIDDEN-TEST RISKS

Even if all visible tests pass, look for implementation/spec mismatches that hidden tests could catch.

Specifically inspect:

### Idempotency

### Time

Verify:

* invalid DST spring-forward times
* fall-back behavior
* absolute duration across DST transitions
* timezone comparisons are performed using instants
* opening hours are respected
* slot-grid rules are respected

### Reservations

Verify:

* capacity
* ownership
* cancellation
* amendment
* conflict detection

* reservation references remain stable
* reservation IDs remain stable where required

### Import/export

Verify:

* valid state round-trips
* invalid state cannot replace live state
* credentials/tokens required by the spec survive
* reservations remain valid after restore
* idempotency receipts remain valid after restore
